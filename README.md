## Install in Chrome

1. Download the ZIP above and extract it into a permanent folder on your computer.
2. Open `chrome://extensions` in desktop Google Chrome.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked**.
5. Select the extracted folder that directly contains `manifest.json`. Do not select the ZIP file.
6. Confirm **Finest Clients Leads** appears and shows version **16.0.30**.
7. Refresh your Facebook tab. Use Chrome's Extensions menu to access the extension; pin it if desired.

Keep the extracted folder in place. Moving or deleting it can stop the extension from loading.

## Update

Stop any active extension task first. Download and extract the new version, then remove the old extension from `chrome://extensions` and load the new extracted folder. Back up any important saved settings before removal, because Chrome can delete extension-local data. Refresh Facebook after installation.

## Troubleshooting

- **Chrome cannot load the extension:** choose the folder containing `manifest.json`, not its parent folder.
- **The extension does not appear:** open Chrome's Extensions menu and check that it is enabled.
- **Facebook changed or an action is uncertain:** stop and inspect the result manually before retrying. Do not repeat uncertain actions, as this can create duplicates.
- **Facebook shows a security challenge or restriction:** stop and follow Facebook's own instructions. Do not bypass challenges or rate limits.
